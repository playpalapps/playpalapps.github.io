# playpalapps.github.io

Public stand-in for the old GitHub Pages address. The Playpal website now lives at
https://playpal.au (source in the private repo `playpal-site`).

- `app-ads.txt` / `ads.txt`: served here directly, because App Store and Google Play
  listings still name playpalapps.github.io as the developer website and AdMob reads
  app-ads.txt from there.
- Every old page forwards to the same page on playpal.au; `404.html` forwards anything else.
